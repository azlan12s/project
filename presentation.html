01 · Problem & Vision

Solving Pop-Culture Fragmentation

Why modern fandom enthusiasts need a unified, moderated, and interactive hub.

The Problem

Fragmented & Passive Portals

  • Fans juggle separate wikis, video sites, convention calendars, and forums across 8 different pop-culture verticals.
  • No unified bookmarking or personal note-taking across articles, characters, and collector merchandise.
  • Lack of local event discovery by geographic distance or calendar integration.
  • Generic chatbots hallucinate off-topic answers instead of linking to verified platform content.
Our Solution

Fan Hub Plus Ecosystem

  • Multi-Level Content Explorer: Filter by Fandom, Genre, Year, Type, and Sort order (`explore.php`).
  • Unified Bookmarks Drawer: Save Articles, Characters & Merch with personal study notes + CSV export (`bookmarks.php`).
  • Leaflet Geolocation Map: Haversine radius search ("Find events near me") + RSVP & `.ics` calendar download.
  • Gamified Engagement: Trivia XP Arena, Fan Rank Badges, and Live Community Polls.
Speaker Note (Slide 2): Explain the core problem from the SRS: pop-culture fans face fragmented portals. Our solution connects discovery, curation, geolocation events, and interactive community challenges under one account.

Gamification Engine

05 · Utility & Personalization

Smart Recommendations, Event RSVP & Data Portability

Practical utilities that real fans and administrators use every day.

Event Utility

RSVP & .ics Calendar

Fans mark Going or Interested on any convention or screening. Clicking Download .ics Calendar generates an RFC 5545 file with GPS coordinates (`GEO`) for Google, Apple, or Outlook Calendar.

Smart Discovery

"For You" Engine

Analyzes each member's `favorite_categories`, bookmarked fandoms, and 4–5★ rated titles to surface personalized recommendations on the Dashboard and Content pages, alongside a session-based Recently Viewed shelf.

Data Portability

1-Click CSV Exports

Members can export their entire Bookmarks & Study Notes drawer (`bookmarks.php?export=csv`), while Administrators can export platform KPI metrics and category views (`admin/index.php?export=analytics_csv`).

06 · Technical Architecture

System Architecture & 17-Table Relational Schema

Clean, dependency-light, fast, and resilient full-stack engineering.

Stack & Security

Full-Stack Architecture

  • Frontend: Semantic HTML5, Custom CSS3 (`app.css` with Dark/Light mode & View Transitions), Vanilla ES6 JS (`app.js`).
  • Backend: Modular PHP 8.x (`includes/functions.php`, `includes/category_template.php`, `assistant.php`).
  • Security Guards: Server-side role checks (`require_login()`, `require_admin()`), CSRF token verification (`csrf_check()`), SQL escaping (`esc()`), and XSS output encoding (`e()`).
  • Self-Healing Schema: `ensure_srs_tables()` and `ensure_upcoming_events()` guarantee zero missing-table errors.
MySQL / MariaDB (3NF)

17 Relational Tables

  • Core Entities: `users`, `categories`, `contents`, `character_profiles`, `merchandise_items`, `events`
  • User Curation: `bookmarks`, `item_bookmarks`, `personal_notes`, `media_ratings`
  • Community & Gamification: `quiz_questions`, `quiz_attempts`, `fandom_polls`, `fandom_poll_votes`, `event_rsvps`
  • Operations & AI: `feedback`, `activity_logs`, `chatbot_queries`, `password_resets`
Speaker Note (Slide 7): Emphasize security and database normalization: every POST form uses CSRF tokens, every admin page enforces server-side role guards, and the database is normalized into 17 tables.
